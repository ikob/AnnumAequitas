# Merrill 形式の架空テストセット

[English](README.md) | 日本語

**全データが架空です。個人の明細を匿名化・転記したものではありません。**
銘柄は架空の Fictional Cloud Corporation / FICT、口座は DEMO-MULTI-0001。
実際の発行会社、株価、為替、配当履歴、個人の保有を表しません。

## 作成元と形式の確認範囲

手元の Merrill エクスポート資料で確認した Activity / Holdings / Portfolio の列構成・日付・数値の表記を模倣（mimic）したものです。実資料の銘柄・数量・金額を置換して作ったものではなく、値と取引履歴は独立に生成しています。Merrill が公開した公式サンプルCSVの転載・改変ではありません。

公開資料の調査（2026-09-26）では、次を確認しました。これらは形式確認の参考リンクであり、本セットの数値の出典ではありません。

- [Merrill公式の明細サンプルPDF](https://oaui.fs.ml.com/Publish/Content/application/pdf/GWMOL/A_Guide_to_Your_Merrill_Edge_Statement.pdf)：売却（Sale）の記載あり。ただしPDFの項目・表記から Activity CSV の出力仕様までは確定できない。
- [公開された Holdings CSV 例](https://www.bogleheads.org/forum/viewtopic.php?start=100&t=394456)：第三者による列構成の実例。公式CSV仕様ではない。
- [Merrill公式の株式分割説明](https://education.ml.com/Publish/Content/application/pdf/GWMOL/StockSplits.pdf)：株数・単価の調整の説明。分割時の Activity CSV サンプルではない。

売却と株式分割を含む実際の Activity CSV サンプルは不足しており、取引名・数量の符号・分割比率や効力日の記録方法は未確認です。特に `split-unsupported/` の `Stock Split` 行はテスト用の仮定で、Merrill がこの形式で出力するという根拠はありません。現在のテストは計算ロジックの検証であり、この2種類のMerrill CSVとの適合確認を完了したものではありません。

## ティッカーと相場データ

本セットでは `FICT` を架空銘柄として明示的に対応付け、同じOHLC形式の架空株価を同梱します。`FICT` や候補の `DUMM` は、このプロジェクト内で架空表記として扱えるものの、実市場で永久に未使用であることを保証する予約名ではありません。文字列だけでデモかどうかを判断せず、記録のデモ指定と同梱の銘柄対応を使います。デモの取引所は `OTHER`（その他・取引所なし）です。実市場の上場銘柄には対応付けません。

実在会社の価格推移を使うケースも追加可能です。その場合は実ティッカー・取得元・取得日・分割調整の有無を明記し、取引と保有は架空であることを区別します。現在のセットには実市場の価格履歴を使用していません。新しく提出する株式fixtureは [CONTRIBUTING](../../../CONTRIBUTING.ja.md) に従いFICT / OTHERを使用してください。

## すぐ画面で見る

現在の個人記録を保存してから、別タブのアプリまたは保存済みの画面で
**Open records → fictional-ledger.json** を開いてください。
デモ表示になり、架空の銘柄対応・株価・為替・収録期間も設定済みです。
これは5年分の Activity と直近の Holdings / Portfolio だけを使い、過去年末を逆算する構成です。

株価・為替バッチの provider / URL は既存の読込形式を試すための模擬メタデータです。
Stooq / FRED から取得したデータではなく、実際のレートや出典の証明として使わないでください。
株価は必要日のみの架空 OHLC、為替も必要日のみの架空レートで、連続した市場履歴ではありません。

## CSV 取り込みを試す

- `activity-2022.csv` 〜 `activity-2026.csv`：5年分、計37行。RSU10件、配当10件、源泉徴収10件、売却7件。
- `activity-all.csv`：上記を1ファイルにまとめた同じ履歴。**年別ファイルとのどちらか一方**を使う。両方を読むと意図した重複検出テストになる。
- `holdings-2022.csv` 〜 `holdings-2026.csv`：年末保有株数と評価額。当年は2026-09-25時点。
- `portfolio-2022.csv` 〜 `portfolio-2026.csv`：同日の現金・投資・純資産。末尾空列も Merrill 形式に合わせている。
- `prices-fictional.csv` / `fx-fictional.csv`：任意で相場取り込みを試すための架空値。

通常は Activity 全期間 + `holdings-2026.csv` + `portfolio-2026.csv` を取り込む。
残りの残高ファイルは年末復元の照合用で、毎年取得できるという製品要件ではない。
CSV 単独では株価画面で FICT・架空の会社名・その他（取引所なし）を対応付けて、prices-fictional.csv を取り込めます。設定済みデモ記録でも確認できます。

## シナリオと確認値

2022年開始時点に、Activity に取得履歴がない40株と現金100 USDを保有。Holding から逆算した40株は、前年の2021-12-31の推定 Opening として表示します。同梱株価40 USDで評価額は1,600 USDです。
源泉徴収はテスト上の仮定として配当の24%（Federal Backup Withholding）をセントで丸める。

売却の Amount は手数料控除後の手取額。手数料は架空の1〜2 USDで説明欄に記載。
**売却CSVの具体的な表記は仮形式で、Merrill の実売却資料との照合は未実施。**

| 時点 | 株数 | 現金 USD | 株式評価額 USD | 純資産 USD |
|---|---:|---:|---:|---:|
| 2022年末 | 120 | 1,145.36 | 5,760.00 | 6,905.36 |
| 2023年末 | 50 | 8,180.36 | 2,600.00 | 10,780.36 |
| 2024年末 | 100 | 9,319.26 | 6,800.00 | 16,119.26 |
| 2025年末 | 125 | 12,674.26 | 9,250.00 | 21,924.26 |
| 2026-09-25 | 175 | 13,641.66 | 14,700.00 | 28,341.66 |

2023年の大口売却は Activity の取得分が10株不足し、初期基準株価で補う参考損益が1,798 USDになる。
その後の売却には Activity の平均取得費で計算できる損失も含む。
`expected.json` は残高と年間フローの照合値。生成処理の現金・数量の繰越から作り、アプリの計算結果をコピーしていない。

## 株式分割の未対応テスト

`split-unsupported/` は通常セットに混ぜず、空の記録へ単独で取り込む。
架空の10株取得 → 1株を2株にする分割 → 4株売却 → 16株保有、というケース。
分割後の取得費総額は1,000 USDのまま、単価は50 USDになるので、対応後の売却損益の検算値は39 USD。

**現在のアプリは分割の比率・効力日・取得単価を調整しない。**
期待する現在の動作は、Stock Split 行が `other` / 要確認となり、売却損益と分割をまたぐ残高逆算を未確認にすること。
Holdings / Portfolio の観測残高は表示できる。分割行がCSVにない場合は自動検出できない。
分割調整済み株価を読み込むだけでは、保有数量や取得費の分割対応にはならない。
