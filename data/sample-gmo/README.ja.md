# GMO Coin形式の架空fixture

[English](README.md) | 日本語

`demo.csv` は完全に架空の取引・日時・数量・金額・IDです。実資料の値は転記していません。GMOの23列の取引履歴形式のみを模倣しています。

- BTC預入→後年の販売所売却→日本円出金を収録。
- 預入は取得費を示さず、所得・買付として計上しません。
- 送付元とトランザクションIDは架空文字列で、実際のアドレスではありません。
- 実例で確認した分類は預入・販売所売却・日本円出金。購入・送付・日本円入金の逆方向は列と区分に基づく対応で、実例照合は未実施です。
- 取引所取引・レバレッジ等の未対応分類は捨てずに未分類として保持します。

通常の「CSVを追加」で取り込み、自動判定またはGMO Coinを指定します。株式とは別の暗号資産ブロックに原通貨JPYと数量増減を表示します。小計は取り込んだ有効行だけのフローであり、残高・利益ではありません。

## 多年データ

`multi-year.csv` は2022〜2026年の22件です。BUY 7件、SELL 6件、BTC/ETH交換3件、円入出金4件、暗号資産預入・送付2件を含みます。`node scripts/generate-gmo-fixtures.ts` で再生成できます。元の3件の `demo.csv` とは独立したシナリオです。テスト用の空の記録に読み込んでください。

BUYの数量はプラス、円支払はマイナス。SELLの逆方向、手数料ありの売買、価格の上昇・下落も収録。値は完全に架空です。BUYの原取得額を保持し、取り込んだ範囲の参考移動平均で売却へ割り当てます。売却ごとの手入力が優先し、履歴不足時だけ5%暫定取得費を使います。

### 交換のテスト拡張

GMOの実際の暗号資産間交換CSV仕様は未確認です。交換3行は**GMO公式形式ではないテスト専用拡張**で、精算区分を `DEMO_CRYPTO_SWAP`、追加列を `交換元資産 / 交換元数量 / 交換先資産 / 交換先数量` としています。実在サービスでこのペアが提供されることを意味しません。

JPY/USDの関わらない交換はユーザー指定により今回の損益・数量増減小計から除外し、交換元・先と数量を原行として保持します。画面では「JPY/USDなし：今回の集計対象外」。これは今回の機能範囲の指定です。JPY/USDが交換列に含まれる場合や未知の実CSV表現はこの除外に入れず、未対応として残します。

実データをfixtureとして提出しないでください。金額・日時・アドレス・IDも独立した架空値にし、氏名だけの置き換えは不可です。BTC/ETHは暗号資産の解析用記号です。株式fixtureはFICT / OTHERを使用してください。
