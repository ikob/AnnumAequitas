# GMO Coin CSV取り込み

[English](GMO.md) | 日本語

## 形式と対応範囲

2026-09-26、ローカルの利用者提供CSVを読み取り専用で調査。UTF-8の23列形式で、`日時 / 精算区分 / 日本円受渡金額 / … / トランザクションID` を持つ。ヘッダーのみの資料も原資料として受け付ける。ファイル名から年・完全な収録期間を推定しない。

`src/brokers/gmo.ts` が形式判定・原行保持・正規化を担当。共通importCsvがMerrill/GMOへ振り分ける。NYSE/NASDAQの証券として扱わず、記録v1のcryptoTransactions（旧保存では空配列）に保存する。復元時は原行から再解析する。

- 販売所取引：買／売を数量の入出庫に正規化。円受渡額は元CSVの符号を保持。
- 暗号資産預入・送付：預入は移動元の取得履歴が必要。購入・所得とは扱わない。
- 日本円入出金：入金／出金を売却益として扱わない。
- 不明分類・不正数値・不明日時を保持し、増減小計から除外。未対応行を黙って捨てない。
- 同一ファイルの再取り込みを防止し、重複候補（約定IDまたは原行一致）は全候補を小計から除外。今回、候補の個別採否操作は未実装。
- 注文手数料・送付手数料は空欄とゼロを分けて保持。円受渡額から二重に手数料控除しない。送付手数料を含む完全な残高復元は未実装。
- 日時は原表記と日付を保持。CSVにタイムゾーン欄がないためUTC瞬間を推測しない。
- 複数のGMO口座を識別する口座欄はない。複数口座の統合には口座指定の拡張が必要。

実例で確認できた分類は預入・販売所売却・日本円出金。逆方向の購入・送付・入金は実例未照合。レバレッジ・取引所取引等は未分類として保存する。

## 表示と限界

CSV追加後、OverviewとReviewに暗号資産取引ブロックを表示。暦年で絞り込み、暗号資産の数量増減と円受渡額の小計、原行・出典を確認できる。JPY原額は株式のUSD/JPY表示切替によって変換しない。

開始残高・年末残高・BTC相場取得・移動元取得費の自動引き継ぎは未実装。株式向けのOpening株価による参考取得費は暗号資産へ自動適用しない。

## 売却取得費の手入力と5%暫定計算

売却の詳細で「この売却数量に対応する取得費総額（JPY）」を入力する。これは売却分への割当額であり、預入全体の取得費ではない。手入力額は保存し、空欄保存で自動に戻す。明示したゼロと空欄を区別する。

手入力も利用できる取得履歴もない場合は、約定金額（売却価額）の5%を仮の取得費とし、日本円受渡金額（手取額）から差し引く。手数料を二重控除しない。預入・出金から利益を作らない。元の売却価額や受渡額が欠ける場合、重複・未対応行の場合は損益を作らない。


表示色はユーザー指定のアプリ内確認基準。暦年の参考損益を売却日ごとのUSD/JPYでUSDへ参考換算し、合計が100,000 USDを厳密に超える場合は赤字。年合計は実装時の前提として説明済み。Allでも年ごとに判定する。取得費未入力の5%計算、値不足、為替未取得はアンバー。為替は既存の同日・次の取得済み観測を使用し、採用日を表示する。

## 多年BUY・交換fixture

`data/sample-gmo/multi-year.csv` に22件の独立した架空シナリオを追加。詳細と再生成方法は同ディレクトリのREADMEを参照。暗号資産間交換は実CSV形式が未確認のため `DEMO_CRYPTO_SWAP` という明示的なテスト拡張だけを識別する。JPY/USDのない交換は集計対象外として保持する。未知の実取引を円欄空白という理由だけで無視しない。BUYの取得額は参考移動平均で売却へ割り当てる。

## Reviewから預入取得費を補う

預入・BUY・SELLの詳細リンクは「取得費を入力・編集」。預入では数量全体に引き継ぐ取得費総額JPYを入力し、預入時価を取得費としない。BUYは円支払額を既定取得費とし手入力で上書きできる。SELLは従来どおり当該売却数量分の総取得費を上書きできる。

売却個別入力→取得履歴の参考移動平均→売却価額5%の順で使用する。既知の預入/BUYだけのプールから先行売却・送付数量を消費する。数量不足・不明取得費は平均値を捏造せず5%へ戻す。小数8桁の割当丸め。利用者指定のJPY/USDなし交換除外は継続するため完全な原価ではない。預入元の自動照合や複数口座を統合した取得費計算は未実装。

入力保存後は詳細を開いたまま保持し、記録の保存・復元でも入力を維持する。過去の「売却だけ入力可能」「BUY自動割当未実装」という記載はこの変更で更新された。

円でのBUYから取得費が追える場合は入力不要。BUY詳細でCSV支払額を表示する。USD/JPY不足はUSD表示・10万USDの確認だけに影響し、円建て取得費を不明扱いにしない。為替不足は独立したアンバー注記とする。
