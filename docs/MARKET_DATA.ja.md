# 日次株価と参考単価

[English](MARKET_DATA.md) | 日本語

2026-09-26。ユーザー指定により、API キー不要の公開 CSV を優先する。
現在は Stooq 形式の日次 OHLC CSV に対応する。公開ダウンロード可能であることと、
オープンライセンスで再配布できることは区別する。調整方法・再配布条件は未確認。

## 画面から使う

1. Review で銘柄を確定する。正式名称・ティッカー・取引所の候補から選ぶ。
2. Market data で確認済み銘柄を選ぶ。CSV の Trade / LAPSE / Settlement Date と開始残高から From / To を自動提案する。初回は必要期間全体、キャッシュがあれば観測期間外の最初の不足区間になる。Prepare download を押す。
3. Stooq のダウンロードリンクを開き、取得した CSV を Import price CSV で取り込む。
4. Overview の暫定金額に取り込んだ同日終値を反映する。単価は採用済み値を優先し、未採用なら同日終値、なければ CB / Price の候補を使用する。Review / Details で単価と出典を比較して選ぶ。自動候補はレビュー済みの採用とは区別する。
5. Save で相場資料・選択値・出典も含む記録 JSON を保存する。

提供元の銘柄表記は `.us` を初期候補にするが、同一銘柄か提供元で確認する。
価格 CSV 自体には銘柄識別子がないため、選択銘柄とファイルの取り違えに注意する。
ブラウザから外部に送るのは利用者が開いた価格 URL の銘柄・期間だけ。
証券会社 CSV、保有数量、口座情報は送らない。ダウンロード画面の認証回避は行わない。

## 増分とキャッシュ

- 銘柄ごとに必要期間を求める。除外行・別銘柄・Grant Date は期間の根拠にしない。
- CSV を追加すると、より古い期間・新しい期間の両方を提案できる。複数の不足区間がある場合は一覧を示し、最初の区間をフォームに設定する。
- 必要期間の終端は最新の資料日。今日までを自動要求しない。任意の期間へ変更でき、Use suggested dates で自動提案に戻せる。
- 検証済み観測データの最小日・最大日の範囲を使う。要求しただけの期間を取得済みにしない。範囲内の欠損日を埋めたり、取引所休日と断定したりはしない。同日価格のない評価候補は未確認のまま。
- キャッシュは銘柄・提供元銘柄・調整区分・通貨・日付ごとにマージしたビューを使う。同じ日を二重に数えず、最新の取得値を候補にする。古い原データは出典付きで保持し、価格や出来高の改訂を画面で展開できる。
- キャッシュと原データは Save の記録 JSON に含まれる。Export price cache で株価だけの JSON にも書き出せる。Import price JSON で別の記録にも再利用可能。ブラウザ永続ストレージへの自動保存は行わない。
- 取り込み後は次の不足区間に提案が進む。観測範囲が必要期間を覆う場合はその旨を表示するが、個別日付の完全性は保証しない。

## ローカル収集コマンド

以下は公開銘柄を使った操作例であり、保有銘柄を意味しない。

```sh
npm run prices -- --symbol AAPL --exchange NASDAQ --from 2024-01-01 --to 2024-12-31
```

自動取得が拒否される場合、ブラウザで取得した CSV を指定する。

```sh
npm run prices -- --symbol AAPL --exchange NASDAQ --from 2024-01-01 --to 2024-12-31 --csv /path/to/aapl.csv
```

必要なら `--provider-symbol` で提供元の表記を指定する。
コマンドは個人記録を読まない。取得内容を検証後、原 CSV を `data/cache/prices/`、
正規化 JSON を `public/prices.json` に保存する。どちらも Git 対象外。
アプリの Market data → Refresh local prices で読み込む。記録ページの再読み込みは不要。
JSON ファイルを画面から取り込むこともできる。
失敗時には既存 JSON を置き換えない。認証用 HTML を株価として解釈しない。

## 保存と候補の意味

- 日次 OHLC・出来高、通貨 USD、NYSE/NASDAQ/OTHER、提供元銘柄、対象期間、出典 URL、取り込み日時、原 CSV の SHA-256 を保存する。
- 保存フィールド `fetchedAt` は自動取得時の収集時刻、手動 CSV 時は取り込み時刻。過去にブラウザでダウンロードした時刻を復元できるわけではない。
- 分割・配当調整は `unknown` のままにする。調整済み履歴を当時の vest 評価単価と断定しない。
- CB と Price は「単価かもしれない」候補で、説明欄・元の値を保持する。価格日が判明したとは扱わない。
- 比較対象日は LAPSE DATE を優先し、なければ Trade Date と明示する。この選択は用途に応じた基準日の確定ではない。
- 同日終値だけを候補にする。休日や欠損は前営業日へ自動補完しない。
- 選択は参考単価のレビューであり、基準日・評価方法・取得費の根拠確認ではない。単価×数量も参考値。
- 採用候補は独立したスナップショットとして保存する。後日の株価更新では上書きしない。銘柄対応を変更すると以前の選択は無効になり、再レビュー対象に戻る。
- 売却代金を終値で代用しない。
- 配当・源泉徴収は通常の金額・日付が揃えば一律のレビューを要求しない。銘柄未解決・欠損・不自然な符号・重複などは従来どおり確認する。

## 調査・動作確認

- [Stooq の日次 CSV エンドポイント](https://stooq.com/q/d/l/?s=aapl.us&i=d&d1=20240101&d2=20240110): この環境で HTML のブラウザ検証ページまたは HTTP 403 が返った。実株価の自動取得は未成功。ブラウザでの取得成功も未確認。
- [Nasdaq Historical Quotes](https://www.nasdaq.com/market-activity/quotes/historical) と [Nasdaq Legal](https://www.nasdaq.com/legal): 公開表示と利用条件を調査。収集元としては採用していない。
- [IRS Backup Withholding](https://www.irs.gov/businesses/small-businesses-self-employed/backup-withholding): 一般の配当源泉徴収と同じ意味と決めつけず、原資料の説明を保持する理由となる一次資料。

検証には架空の OHLC と架空の証券会社 CSV のみを使用。
CSV 検証、日付一致、参考値の保存・復元、更新時の固定、銘柄変更、現金行の確認条件、
収集失敗時のキャッシュ保護をテスト。今回の UI 追加は Safari 操作の競合により実画面での確認が未完了。
