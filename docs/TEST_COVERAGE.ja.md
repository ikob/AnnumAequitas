## 数値の範囲と限界

- `--test-coverage-include='src/**'`で、テスト・依存ライブラリ・scriptsを集計から外す。現時点ではsrcのTypeScript 26ファイル中25ファイルがレポートに現れる。
- **main.tsはテストから読み込まれず、分母にも含まれていない。上記99.44%はアプリ全体のカバレッジではない。** ブラウザ操作は後述のPlaywrightで別途検証し、この単体カバレッジ率には合算しない。
- scriptsには子プロセスでのテストがあるが、上記src限定の率には含めない。CSS、HTML、GitHub Actions、外部サービス実取得も別途検証が必要。
- テンプレートを1行に記述したファイルでは、行100%でも多数の条件分岐が未実行になり得る。分岐と関数も確認する。i18n辞書も全体の行数に含まれ、全体行率を押し上げる。
- 実資料との照合、独立した期待値、根拠資料は別の受入条件。

## CIの最低ライン

計測対象全体で行95%・分岐80%・関数90%。個別ファイルの最低値ではない。CIは閾値未達またはテスト失敗で不合格になり、coverageレポートを30日保存する。新規ファイルがレポートに載ること、重要な変更分にテストがあることはレビューで確認する。判定の詳細は [CONTRIBUTING.md](../CONTRIBUTING.ja.md) を参照。

## ヘッドレスChromeのE2E

2026-09-26のローカル実行で17シナリオすべて成功（約18秒、ブラウザ準備・ビルド時間を除く）。単体81テストとビルドも成功。

Playwrightでビルド済みアプリを専用の127.0.0.1:4178で起動する。ユーザーのブラウザや記録には触れず、テストごとに独立したブラウザコンテキストを使う。外部通信とローカル相場キャッシュの読み込みを遮断し、公開用の架空fixtureだけで検証する。

- 明示同意前は利用不可、同意Cookieの実保存、再読み込み、旧版Cookieで再同意。
- GMOのCSV取り込み→Reviewで取得費300万円入力→売却分取得費80万円・利益40万円。預入のsettlementは空欄のまま。ダウンロードした記録を再読み込みして結果を確認。
- MerrillのCSVと架空株価CSV取り込み、Review候補の往復選択と解除、株式/暗号資産混在時の折りたたみと画面移動後の状態。

実行: `npm run test:e2e`。Playwrightは `npm start` を使い、prestartによるビルドから起動まで検証するため、CIの別build工程は不要。Google Chromeが未導入なら `npx playwright install chrome`。CIは `npx playwright install --with-deps chrome` で準備し、単体テスト・ビルド・E2Eすべての成功を要求する。HTMLレポートと失敗時のスクリーンショット・traceを30日保持。`npx playwright show-report`でローカルレポートを開ける。

設定は [Playwright公式CI手順](https://playwright.dev/docs/ci) に基づく。ローカルChromeで実行確認し、GitHub-hosted CIはpush後の初回実行待ち。Safariや全操作を検証済みという意味ではない。
